# Diretório Estruturado — Refatoração Documental Pós‑Doc

Este diretório organiza os arquivos Markdown recentes em uma camada navegável, técnica e acadêmica, sem quebrar o conteúdo original.

## Navegação rápida

- `00_indice/MD_ULTIMOS_2_DIAS.md` — inventário dos MD alterados nos últimos 2 dias.
- `01_arquitetura/ARQUITETURA_DOCUMENTAL_POSDOC.md` — desenho formal da arquitetura documental.
- `02_metodologia/PROTOCOLO_CIENTIFICO_E_FALSIFICABILIDADE.md` — protocolo de teste científico e falsificabilidade.
- `03_bibliografia/BIBLIOGRAFIA_ACADEMICA_E_REFERENCIAL.md` — base bibliográfica de alto rigor.
- `04_protocolos/TEMPLATE_ARTIGO_TECNICO.md` — template padronizado para artigos internos.
- `05_rastreabilidade/MATRIZ_RASTREABILIDADE.md` — rastreabilidade entre hipótese, dados e evidência.

## Resultado prático

- Estrutura navegável.
- Formalização acadêmica avançada.
- Preparação para testes de falsificabilidade.
- Base para evolução em papers técnicos e dissertação.
