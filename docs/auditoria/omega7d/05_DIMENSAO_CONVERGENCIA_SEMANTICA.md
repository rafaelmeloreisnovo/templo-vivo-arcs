# Ω7D — Dimensão 5: Convergência semântica e arquitetural

## Objeto
Encontrar operações estruturais equivalentes em materiais distantes sem confundir analogia com identidade técnica.

## Invariante
`representação + persistência + identidade + temporalidade + derivação + governança + aplicação`

## Método
Para cada artefato, extrair:
- função primária;
- entrada/saída;
- estado preservado;
- transformação;
- mecanismo de identidade;
- relação com artefato anterior/posterior;
- limite epistemológico.

## Heurísticas de permutação
- H1: `norma -> execução`: uma regra anterior torna-se mecanismo técnico posterior;
- H2: `memória -> proveniência`: armazenamento passa a carregar origem e derivação;
- H3: `hash -> jurídico`: identidade técnica passa a sustentar evidência documental;
- H4: `configuração -> governança`: invariantes declarativos tornam-se requisitos operacionais;
- H5: `conversa -> código`: um evento cognitivo é materializado em artefato versionado;
- H6: `código -> relatório`: execução produz receipt/documentação auditável;
- H7: `área_A x área_B`: só registrar convergência quando houver operador comum identificável.

## Regra anti-inflacionária
Sem operador comum verificável, classificar como `ANALOGY_ONLY`.

Convergência não implica novidade mundial, causalidade científica ou equivalência entre domínios.

## Saída
`NODE_A --[operator]--> NODE_B`, com evidência e força do elo.
