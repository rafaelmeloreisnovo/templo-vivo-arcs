# Templo Vivo ARCS — Matriz de Licenciamento e Proteção

**status:** DRAFT_REVIEW_REQUIRED  
**claim_allowed:** false  
**software_grant:** TOKEN_VAZIO

Este diretório separa domínios que não devem ser fundidos em um único texto jurídico.

## Camadas

| Arquivo | Domínio | Efeito pretendido |
|---|---|---|
| `COPYRIGHT_NOTICE.md` | autoria e direitos autorais | registrar titularidade/atribuição sem inventar autoria de terceiros |
| `CULT_WORSHIP_NOTICE.md` | liberdade de consciência e culto | proteger o espaço de manifestação espiritual sem controlar crenças alheias |
| `PRIVACY_NOTICE.md` | privacidade e dados | estabelecer minimização, consentimento/base jurídica, redação e custódia |
| `SACRED_INTEGRITY_POLICY.md` | não-profanação/integridade | regra ética de não adulteração, falsificação ou exposição abusiva |
| `SOFTWARE_LICENSE_DECISION.md` | código | registrar que o grant jurídico do software ainda exige decisão explícita |

## Invariantes

`CULTO != COPYRIGHT != LICENÇA_DE_SOFTWARE != PRIVACIDADE != REGRA_ESPIRITUAL`

`PUBLIC_REPO != CONSENTIMENTO_PARA_EXPOR_DADOS_PRIVADOS`

`REGRA_ESPIRITUAL != OBRIGAÇÃO_JURÍDICA_AUTOMÁTICA`

`TOKEN_VAZIO != AUTORIZAÇÃO`

## Root LICENSE

O arquivo `LICENSE` histórico não é automaticamente tratado como licença de software convencional. Ele permanece como evidência histórica até migração explícita e revisada.

Nenhuma licença SPDX é promovida por este pacote.
