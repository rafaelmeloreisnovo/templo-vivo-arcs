# Estado Fractal HAJA

Implementação operacional do núcleo **Estado + Fractal + HAJA**, com trilha de governança, prova criptográfica e camada de conformidade jurídica.

## Objetivo
- Executar módulos rastreáveis (sem execução opaca).
- Registrar prova de integridade por hash + timestamp.
- Aplicar validação formal (direitos humanos, não coerção e rastreabilidade).

## Estrutura
- `src/core`: motor de estado, expansão fractal e acionamento HAJA.
- `src/governance`: regras e validação constitucional/humanitária.
- `src/espiritual`: camada simbólica operacional (templo vivo).
- `src/proof`: geração de provas técnicas (hashes, Merkle root simplificada).
- `legal`: base de compliance e tratados.

## Execução rápida
```bash
python3 run.py --nome "Estado Fractal HAJA" --profundidade 4 --registro manifesto/livro-vivo.md
```

## Dependências
Instalação recomendada:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
