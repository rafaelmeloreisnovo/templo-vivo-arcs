# Software License Decision Gate — Templo Vivo ARCS

**status:** TOKEN_VAZIO / DECISION_REQUIRED  
**claim_allowed:** false  
**spdx_id:** TOKEN_VAZIO

O repositório contém código, documentação, dados, mídia e material espiritual. Não é seguro inferir uma única licença para todos esses domínios.

## Estado atual

O arquivo `LICENSE` histórico contém manifesto e texto conversacional, não um grant convencional e inequívoco de software. Por isso, este pacote não promove automaticamente MIT, AGPL, GPL, Apache, PolyForm ou qualquer outro identificador SPDX.

## Decisão necessária

Antes de substituir o `LICENSE` raiz, deve ser escolhida explicitamente a política para **código original do Templo Vivo ARCS**, considerando:

- permissividade desejada para uso, cópia e distribuição;
- exigência ou não de copyleft;
- uso comercial ou não comercial;
- distribuição de modificações e forks;
- compatibilidade com dependências e código herdado;
- separação entre código, documentação, dados e conteúdo espiritual;
- atribuições e licenças de terceiros.

## Gate

A licença de software só sai de `TOKEN_VAZIO` quando houver:

1. decisão explícita do titular sobre o grant desejado;
2. inventário mínimo de componentes herdados/terceiros;
3. verificação de compatibilidade básica;
4. texto canônico da licença escolhido sem cláusulas simbólicas conflitantes;
5. atualização do índice e receipt da decisão.

Até esse fechamento, `PUBLIC_REPO != OPEN_SOURCE_GRANT_AUTOMÁTICO`.
